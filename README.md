# Global Health Connect

Connecting Healthcare Globally.

## Project Overview

Global Health Connect is a platform dedicated to bridging the gap in healthcare accessibility and information. This project is built using modern web technologies to ensure a fast, responsive, and reliable experience for users worldwide.

## Technologies Used

- **Vite**: Next Generation Frontend Tooling
- **React**: A JavaScript library for building user interfaces
- **TypeScript**: Typed JavaScript at Scale
- **Tailwind CSS**: A utility-first CSS framework
- **Radix UI**: Unstyled, accessible components for building high-quality design systems
- **GSAP**: Professional-grade JavaScript animation for the modern web

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or bun

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```bash
   cd global-health-connect
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

### Development

Start the development server:
```bash
npm run dev
```

### Build

Build the project for production:
```bash
npm run build
```
